# VT 職位與人才管理系統｜本機使用說明

## 啟動方式

Node.js 需求為 `>=22.18.0`（本次驗證使用 Node.js 24）。

在「系統」資料夾執行：

```bash
npm run dev
```

看到 `http://localhost:3000/` 後，以瀏覽器開啟該網址即可使用。

## 第一版功能

- 上方導覽：管理總覽、組織圖、工作說明書、人員盤點及職能盤點。不再設獨立職位列表；組織圖提供組織總覽，工作說明書提供主檔總覽表。
- 管理總覽：查看職位、編制、現職，以及尚未完成主管確認的職位。
- 組織圖：由上往下呈現，同層單位並排；職位預設收合，可依協理層級、部門主管層級或全部展開，較寬的組織圖可水平捲動。
- 工作說明書狀態：職位節點以蛋黃色表示尚未完成職位確認；確認完成後恢復灰色職位卡。單位卡右下角會加總顯示現任人數／編制人數。
- 組織資料狀態：來源簡表標示「待確認」的單位節點使用淺綠色，並顯示「單位・待確認」；這與工作說明書的蛋黃色確認狀態分開管理。
- 單位主管：單位卡顯示主管姓名與主管職位；點擊單位後可在單位明細編輯主管資料及部門執掌。
- 單位明細：點擊 VT廠、行政幕僚、現場幕僚等單位，可編輯部門執掌及「待確認／已確認」組織狀態。
- 組織編輯：展示模式可安全瀏覽；進入組織編輯模式後，可新增、刪除或拖拉節點。
- 工作說明書：以八欄表格呈現每份主檔；點入後使用與組織職位相同的文件版型。
- 職位明細：可修改職位資料、編制人數、現任者，以及該職位唯一一組確認狀態、確認人、日期及備註。
- 工作說明書主檔：每份工作說明書都有不可重複的代碼，可新增或編輯；同一份主檔可供多個組織職位共同引用。
- 組織職位關聯：由組織圖點擊職位節點進入明細，在「工作說明書關聯」選擇主檔。變更共用主檔內容會同步反映在所有引用職位，但各職位的單位歸屬、編制、現任者及接班人仍分開保存。
- 工號帶入人員：先在人員盤點明細維護每位人員的唯一工號；之後在職位明細輸入工號，即可自動帶入姓名並建立現任者或潛在接班關係。
- 人員盤點：以條列式顯示人員、現任職位、潛在接班職位、盤點文件與確認階段；點擊人員可編輯資料及職位連結。
- 多對多職位關係：同一人可連結多個職位；同一職位可連結多位現任者或潛在接班人。
- 確認流程：待確認 → 在職人員確認 → 主管確認。
- 全站搜尋：頁首可切換依職位或部門搜尋。
- 顯示語系：頁面右上方可切換繁體中文／簡體中文，系統會記住這台電腦上次使用的語系。
- 列印／PDF：由職位或工作說明書明細點選列印按鈕，於瀏覽器選擇印表機或「另存為 PDF」。採 A4 緊湊雙欄，審核者、版本、狀態及生效日均列印；建議關閉瀏覽器頁首頁尾以免附上網址。頁數依正文長度決定，不強行縮成一頁。

## 工作說明書總覽與版本管理（2026-09-15）

總覽依序呈現八欄：代碼、職務名稱、已關聯、現職者、接班者、最新版本、狀態、生效日。每份主檔一列，共用於多個職位也不重複；人數依實際關聯去重，不使用範例人數。

- 點代碼、職務名稱或最新版本，查看文件；點「歷史版本」直接展開版本歷程。
- 最新版未生效時，總覽與明細提示目前有效版；組織職位仍使用有效版內容。尚無有效版時顯示現有草稿及其原狀態。
- 點職位數查看關聯單位與編制；點人數查看名單並進入人員盤點。人數由明確的人職關聯去重，不以盤點文件數計算，也不推定接班準備度。
- 可依代碼／職務／部門搜尋、篩選狀態及按生效日排序。沒有生效日期的文件排在有日期者之後。
- 狀態同時顯示文字與底色：正式生效綠色、主管確認中藍色、待確認／待修正橘色、草稿灰色、已失效深灰色。

### 審核者與文件呈現

- 工作說明書及組織職位明細的職能標籤依代碼分色：M 管理職能淺藍、P 專業職能淺黃、L 語言能力淺綠，未分類淺灰。保留代碼及名稱，滑鼠停留可查看類型；列印樣式沿用配色，不改資料。

- 共用原職位明細版型；資料來源、摘要、訪談重點與備註／待確認輔助區塊不顯示、不列印，但原始資料仍保留。
- 審核者隨版本保存，網頁與 PDF 都顯示；編輯草稿時可修改。未提供者顯示「待確認」，不推定為現任者或主管。
- 指定 11 份文件預填 v1、生效日 2026/09/14：環安／IE／產效改善／精實改善＝石旻錡；業務＝潘姵如；採購＝覃秋玲；底部＝曾建兵；面部副協理與面部副理＝李紅星；行政幕僚＝楊旻軒；現場幕僚＝徐季瑋。未指定的廠主管保留原資料。
- 預填日期與審核者不代表已審核或正式生效；文件狀態維持原值，正式生效仍需明確操作。

### 建立與改版

1. 按「新增工作說明書」，填代碼、職務名稱、版本與內容後儲存草稿。
2. 代碼與版本號建立後固定；可修改尚未生效的最新版內容及確認資料。
3. 準備正式採用時，按「正式生效」、填寫有效日期並再次確認。日期不得晚於今天；本版內容鎖定，原有效版轉為已失效。
4. 需要改版時按「新增版本」，填比最新版更大的版本號。系統複製內容供修訂、清空生效日期與確認資料；原有效版繼續適用。
5. 完成修訂後重複第 3 步，組織關聯不必重設。

同一主檔一次維護一份待生效草稿。生效或歷史版本不可直接覆寫；版本歷程保留原生效日及被新版取代的失效日。既有正式生效文件若原本缺少有效日期，顯示「待補日期」，不自行補日期。

本次保留現有 12 份文件為各自第一個版本快照，不臆建先前未保存的版本。人員名單永遠表示目前關聯，不是歷史版本當時的人員快照。

## 組織職位關聯流程

1. 從上方「工作說明書」建立或選擇要共用的主檔。
2. 需要正式採用時，先完成該版本的正式生效操作。
3. 回到「組織圖」，點擊要套用的職位節點。
4. 在職位明細上方的「工作說明書關聯」選取代碼並確認。
5. 同職務的其他節點重複第 3～4 步，選取同一代碼即可共用同一份文件。

目前 `VT1面部`、`VT2面部`、`VT3面部`、`VT5面部` 的面部副理均關聯 `JD-VT-012`。

編輯職位期間會暫停切換主檔關聯；請先儲存或取消編輯。組織職位頁只編輯配置與人員，共用內容統一到工作說明書管理。職位明細提供「查看最新版與歷史版本」入口。

## 目前限制

- 本機版尚未加入登入與權限；請勿對外開放網址。
- 組織編輯模式目前以操作模式隔離，正式部署後再限制為 Admin。
- 目前人員及人員盤點為 0 筆，等待指定來源；尚未提供盤點章節的網頁編輯、接班準備度評分及培訓計畫功能。
- 緊湊 PDF 已以合成資料驗證；尚未完成全部真實文件逐頁及繁／簡兩語的列印驗收。
